# Bellora Foods Restaurant Website

## What the webpage is about

Bellora Foods is a restaurant webpage designed to showcase the restaurant, its signature dishes, dining experience, customer testimonials, and reservation form. The webpage allows visitors to explore the menu, learn about Bellora Foods, and make a table reservation.

## AI Tool Used

**AI Tool:** ChatGPT

## How AI Helped

ChatGPT helped me create and improve the webpage by:

* Generating and organizing the HTML structure.
* Creating and improving the CSS styling and responsive design.
* Adding JavaScript functionality for the reservation form and smooth navigation.
* Improving the visual appearance with animations, hover effects, buttons, and responsive layouts.
* Suggesting ways to make the restaurant website more attractive and interactive.
